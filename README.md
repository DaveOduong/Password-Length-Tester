# Password Strength Indicator

## Project Description
The Password Strength Indicator is a simple web application developed using HTML, CSS, and JavaScript. It checks the length of a password as the user types and provides instant visual feedback by categorizing it as Weak, Medium, or Strong.

## Technologies Used
- **HTML5:** Creates the webpage structure and password input field.
- **CSS3:** Handles the layout, colours, styling, and positioning.
- **JavaScript:** Evaluates password length and dynamically updates the strength indicator.

## How It Works
1. The user enters a password into the input field.
2. JavaScript detects changes using an input event listener.
3. The password length is checked automatically.
4. The strength level and corresponding colour are displayed.

## Password Strength Levels
- **Weak:** Less than 4 characters (Red).
- **Medium:** 4–7 characters (Yellow).
- **Strong:** 8 or more characters (Green).

## Project Files
- `index.html` – Contains the HTML structure and JavaScript functionality.
- `style.css` – Contains the webpage styling and layout.
- `arrow.png` – Image used as the button icon.

## How to Run
1. Place all project files in the same folder.
2. Ensure the `arrow.png` image is available.
3. Open `index.html` in a web browser.
4. Enter a password to see its strength indicator update automatically.

## Learning Outcomes
- Understanding HTML password input fields.
- Applying CSS styling and positioning.
- Using JavaScript event listeners.
- Manipulating HTML elements through the DOM.
- Applying conditional statements.
- Creating dynamic visual feedback.

## Conclusion
This project demonstrates how HTML, CSS, and JavaScript can work together to create an interactive password strength indicator. It provides a practical introduction to DOM manipulation and real-time user input validation.

**Note:** Password strength is determined by character length only, not by complexity or resistance to guessing.
